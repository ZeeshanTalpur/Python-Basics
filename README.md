# 🐍 Python-Basics

A collection of beginner-to-intermediate Python scripts covering core language fundamentals — built while learning Python from the ground up, one concept at a time. 📚

## 📂 What's Inside

| # | File | Topic |
|---|------|-------|
| 1 | `1. Variables and DataTypes.py` | Variables, data types, type casting |
| 2 | `2. Strings.py` | String creation, methods, formatting, slicing |
| 3 | `3. Conditional Statements.py` | `if` / `elif` / `else`, logical operators |
| 4 | `4. Lists and Tuples.py` | Lists, tuples, indexing, mutability |
| 5 | `5. Dictionary and Set.py` | Dictionaries, sets, key-value operations |
| 6 | `6. Loops.py` | `for` and `while` loops, loop control statements |
| 7 | `7. Functions and Recursion.py` | Functions, parameters, return values, recursion |
| 8 | `8. File Input Output.py` | Reading/writing files, file handling |
| 9 | `9.OOPs.py` | Classes, objects, OOP principles |

## 💪 Practice Sets

Nine standalone practice scripts (`Practice Set 1.py` → `Practice Set 9.py`) reinforcing the concepts above through hands-on problem solving.

## 📄 Supporting Files

- `demo.txt`, `numbers.txt`, `practice.txt` — sample text files used by the File I/O scripts and practice exercises.

## 🚀 Getting Started

1. Clone the repo:
   ```bash
   git clone https://github.com/ZeeshanTalpur/Python-Basics.git
   ```
2. Navigate into the folder:
   ```bash
   cd Python-Basics
   ```
3. Run any script with Python 3:
   ```bash
   python "1. Variables and DataTypes.py"
   ```

## 🛠️ Requirements

- Python 3.x
